# Tech-Watcher
An intelligent technology monitoring tool that notifies you of new trends based on your interests.

## Features
- Automatic collection from multiple sources
- NLP for content personalization
- Smart desktop notifcations
- Customizable profiles without creating an account
- Trend Visualization dashboard

## Installation
```bash
pip install tech-watcher
```
## Quick Use
```python
from tech_watcher import TechWatcher
watcher = TechWatcher()
watcher.start()
